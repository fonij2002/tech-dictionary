## What is the point of this project?

To help curious learners, especially product builders, understand tech jargon in plain English and make sense of the technology behind what they're building.

## Run locally

```bash
git clone https://github.com/fonij2002/tech-dictionary.git
cd tech-dictionary
pnpm install
pnpm dev
```

Built with **Astro, TypeScript, and Bootstrap**, deployed to **GitHub Pages**.

## Contribute

Add or improve entries in `data/terms/*.yaml`, include reliable sources, and open a pull request. Before submitting:

```bash
pnpm check
```
